# Capoworks ECU Overview

## What is Capoworks ECU

Capoworks ECU is an engine-control firmware distribution built on established open-source ECU
projects. It provides a common platform for configuring and tuning supported engines, with a
documentation set that brings together the firmware interface, supported hardware designs,
vehicle-specific guidance, and the engine-management concepts needed to use them.

Hardware compatibility depends on the board design, firmware build, and configuration definition.
Use the material in this documentation together with the documentation for your specific board and
the release notes for the Capoworks firmware you are running.
