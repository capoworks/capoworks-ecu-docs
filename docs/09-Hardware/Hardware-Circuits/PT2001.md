# PT2001 Low-Z Driver

PT2001 is an NXP solenoid controller. Capoworks exposes a low-impedance fuel or
high-pressure pump solenoid driver through a firmware wrapper named
`mc33816.cpp`, an implementation class named `Pt2001`, and an
`EFI_MC33816` feature; TunerStudio uses both PT2001 and MC33816 labels. Those
shared firmware labels do not make MC33816, PT2000, and PT2001 interchangeable
parts. The wrapper header identifies MC33816 as an NXP programmable gate driver
IC for precision solenoid control and points to NXP application note AN5203 for
MC33816/PT2000 differences; those labels do not establish ratings or
compatibility for another part or board assembly. Verify the fitted part and
board schematic.

The wrapper derives from the `Pt2001Base` interface. It supplies 16-bit SPI
exchange, chip-select selection, `ResetB`, `DRIVEN`, optional `FLAG0` input,
battery-voltage access, reset/enable control, and parameter callbacks. Initial
setup is skipped unless chip-select, reset, and driven pins are valid; the
configured SPI device must also exist. Initialization is retried only when the
battery signal is suitable. This establishes the firmware interface, not an
electrical pinout for any board.

In this source snapshot, `EFI_MC33816` defaults to true for the STM32F4 port and
false for F7 and H7. These defaults are not an absolute STM32F4 processor
prerequisite: check that the actual EFI build target and any board-level build
definitions compile `EFI_MC33816`. The low-Z control dialog can configure a
compiled driver but cannot enable a driver omitted from the firmware build.
The dialog exposes SPI device, chip-select, reset, flag, boost voltage,
boost/peak/hold currents, peak and bypass timing, hold timing, and pump
current/timing controls. Use solenoid and driver documentation plus a
board-specific commissioning procedure; no values are universal.

If initialization fails, first confirm the board target compiles with the
feature, then the SPI device, required GPIOs, battery supply, and the reported
`PT2001 error`. Do not change current or timing values to compensate for an
unverified part or pin assignment. The shared `Pt2001Base` interface is
supplied by the pinned `firmware/ext/libfirmware` submodule; this page documents
the Capoworks adapter contract and does not infer internal protocol or pinout
details. See [Low-Z Injector Driver](/Hardware/Aux-Hardware/Low-Z-Injector-Driver)
for the hardware introduction.
