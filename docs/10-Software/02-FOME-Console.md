# ECU Console

ECU Console is bundled with a matching firmware release and is generally only compatible with the
release in use with the ECU. Obtain current releases and CI artifacts from the
[Capoworks firmware repository](https://github.com/capoworks/capoworks-ecu), including its
[releases](https://github.com/capoworks/capoworks-ecu/releases) and
[Actions](https://github.com/capoworks/capoworks-ecu/actions).

Capoworks distributions may retain the inherited executable name, such as `fome_console.exe`; use
the executable supplied in the matching bundle. The inherited filename is a technical identifier,
not evidence that an upstream bundle is compatible.
